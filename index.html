வகுப்பறை உதவியாளர்

கீழே உள்ள பொத்தானை Chrome புத்தகக்குறி பட்டிக்கு இழுத்துச் செல்லவும். பாடத்தின் போது அதை அழுத்தினால் இடப்புறத்தில் புதிய ஆசிரியர் கருவிப்பலகை திறக்கும்.

1
புத்தகக்குறி பட்டியை காட்டவும்: Ctrl + Shift + B
2
கீழே உள்ள பொத்தானை புத்தகக்குறி பட்டிக்கு இழுக்கவும்.
3
பாடத்தின் போது “வகுப்பறை உதவியாளர்” என்பதை அழுத்தவும்.
✦ வகுப்பறை உதவியாளர்
பழைய புத்தகக்குறியை இந்தப் புதிய பதிப்பால் மாற்றவும்
குறிப்பு: புதிய தாவல், அமைப்புகள் அல்லது Chrome Web Store போன்ற Chrome-இன் உள் பக்கங்களில் JavaScript புத்தகக்குறிகள் இயங்காது. சாதாரண இணையப் பக்கத்தில் பயன்படுத்தவும்.
